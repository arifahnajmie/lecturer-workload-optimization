# User Stories

## User Story 1 (FR1): Upload Lecturer Workload Data
As an academic administrator staff, I want to upload the lecturer workload data in a file, so that I can provide the information for analysis workload and optimization.

Acceptance Criteria:
The system will accepts the file that contains which all of the lecturer workload fields are required and the system display an error message if the information in the file are missing.

## User Story 2 (FR4): Optimize Teaching Assignments
As a faculty workload coordinator staff, I want to generate optimized teaching assignments, so that the teaching responsibilities can be distributed more fairly.

Acceptance Criteria:
The system can generates proposed assignments using Genetic Algorithm (GA) and the generated assignments can satisfy predefined lecturer workload limits.

## User Story 3 (FR5): Compare the Workloads
As an academic administrator staff, I want to compare the workloads before and after optimization, so that I can evaluate the balance of teaching responsibilities among the lecturers.

Acceptance Criteria:
The system will display a lecturer workloads before and after optimization. Other than that, the system also display a numerical workload balance metric for both allocations.
